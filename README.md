# AI-integrated-chess-
A simple chess game with basic move display and AI decision-making. The AI evaluates moves based on basic logic, and the game board is displayed to allow user input. The project can be expanded to support more advanced AI strategies like Minimax for better gameplay.

A simplified chess game using OOP principles. It displays the board and simulates basic moves with AI hooks.

- Move interface
- Placeholder for AI engine
